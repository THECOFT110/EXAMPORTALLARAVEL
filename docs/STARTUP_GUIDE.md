# Startup Guide (Laravel)

## Prerequisites

- PHP 8.3+ (8.5 recommended) with extensions: `pdo_pgsql`, `gd`, `intl`, `mbstring`, `xml`, `zip`
- Composer 2
- PostgreSQL 14+
- Node.js 20+ and npm (for Vite assets)

## First-Time Setup

```bash
# 1. Install PHP dependencies
composer install

# 2. Install frontend dependencies and build assets
npm install
npm run build

# 3. Configure the environment
cp .env.example .env
php artisan key:generate

# 4. Edit .env and set the PostgreSQL connection
#    DB_CONNECTION=pgsql
#    DB_HOST=127.0.0.1
#    DB_PORT=5432
#    DB_DATABASE=salu_exam_portal
#    DB_USERNAME=postgres
#    DB_PASSWORD=...

# 5. Run migrations and seeders
php artisan migrate --seed

# 6. Create the public storage symlink (student photos, documents)
php artisan storage:link
```

## Running the Application

```bash
# Start the dev server (http://127.0.0.1:8000)
php artisan serve

# In a second terminal: hot-reloading frontend assets
npm run dev

# In a third terminal: process the queue
# (PDF generation, seat allocation, fee expiry, email notifications)
php artisan queue:work
```

To reset everything during development:

```bash
php artisan migrate:fresh --seed
```

## Database

This project uses **PostgreSQL**. Useful commands:

```bash
# Run pending migrations
php artisan migrate

# Rollback the last batch
php artisan migrate:rollback

# Check migration status
php artisan migrate:status

# Add a new migration
php artisan make:migration add_performance_indexes
```

Inspect the database with `psql` or any PostgreSQL client (DBeaver, pgAdmin, TablePlus):

```
psql -h 127.0.0.1 -U postgres -d salu_exam_portal
```

## Configuration

All configuration lives in the `.env` file. Key settings:

| Variable | Purpose |
|---|---|
| `APP_KEY` | Encryption key (generated by `key:generate`) |
| `DB_*` | PostgreSQL connection |
| `QUEUE_CONNECTION=database` | Background jobs table |
| `CACHE_STORE=file` | Cache (switch to `redis` in production) |
| `SESSION_DRIVER` | Sessions (use `database` in production) |
| `MAIL_MAILER=log` | Emails written to `storage/logs/laravel.log` (use `smtp` in production) |

**Never commit `.env`.** Production secrets belong in your host's environment variables (Railway/Render/Docker all inject them).

## Testing Features

```bash
# Health check endpoint
curl http://127.0.0.1:8000/up

# API registration returns validation errors (422)
curl -X POST http://127.0.0.1:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"invalid","password":"weak"}'

# Login and use a Sanctum token
curl -X POST http://127.0.0.1:8000/api/auth/login -H "Content-Type: application/json" \
  -d '{"email":"student@example.com","password":"password"}'
```

## Troubleshooting

### Port Already in Use

```bash
# Find the process using port 8000
netstat -ano | findstr :8000

# Kill it (Windows)
taskkill /PID <process_id> /F

# Or run on another port
php artisan serve --port=8080
```

### Database Connection Issues

1. Verify PostgreSQL is running and reachable on `5432`
2. Check `DB_*` values in `.env`
3. Recreate the database from scratch:

```bash
php artisan migrate:fresh --seed
```

### Blank Styles / Missing Assets

```bash
npm run build
php artisan storage:link
```

### Stale Config or Routes After Changes

```bash
php artisan optimize:clear
```
